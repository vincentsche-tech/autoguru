      Frequently asked questions
      
    
      
      
      How does the eBay Motors listing generator work?
      
      
      Paste your supplier data package (product title, OEM / interchange part numbers, application list, specifications) and the tool extracts part numbers, fitment data and specifications, then generates three Cassini-optimized titles, complete Item Specifics, a fitment table and a compliant HTML description you can paste straight into eBay.
      
      
      Are the generated titles within eBay's 80-character limit?
      
      
      Yes. Every title is engineered to stay at or under 80 characters, following the Part Type + OEM/Interchange + Fitment + Placement keyword structure that eBay's Cassini search engine rewards.
      
      
      Is the HTML description compliant with eBay's ActiveContent policy?
      
      
      Yes. The generated description uses only eBay-allowed tags, contains no external links, no JavaScript and no active content, and is mobile-friendly.
      
      
      Does the tool catch errors in my supplier data package?
      
      
      It flags suspicious points found inside your data package — such as left/right pairing conflicts, piece-count mismatches or fitment inconsistencies — as Notes to Seller so you can double-check before publishing.
      
      
      How much does it cost?
      
      
      You can generate 3 listings per day for free. The Pro plan ($9/month) unlocks 30 listings per day, batch CSV processing and priority generation.
